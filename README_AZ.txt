QURULUM
Bütün faylları (qovluqlarla birlikdə) hostinqin əsas qovluğuna (public_html / www) yükləyin. index.html açılış səhifəsidir.
Heç bir server və ya verilənlər bazası lazım deyil.

NƏTİCƏLƏRİ YENİLƏMƏK
1. admin.html faylını brauzerdə açın (öz kompüterinizdə, sayta yükləmək məcburi deyil).
2. Tur nəticələrini mətn kimi yapışdırın, "Analiz et" basın.
3. "Yenilənmiş data.js-i yüklə" basın və js/data.js faylını yenisi ilə əvəz edin.
Cədvəl, bombardirlər, statistika, komanda səhifələri avtomatik yenilənir.

AYARLAR
js/config.js: YouTube, Instagram, Facebook, TikTok, telefon, e-poçt. Boş buraxılanlar saytda görünmür.
