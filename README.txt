SUMQAYIT SUPER LIQA — PREMIUM SITE

Fayllar:
- index.html: saytın əsas səhifəsi
- style.css: dizayn və mobil uyğunluq
- script.js: oyunlar, turnir cədvəli, komandalar və bombardirlər
- assets/: istifadəçinin göndərdiyi liqa və komanda loqoları

GitHub Pages-ə yerləşdirmə:
1. ZIP-i aç.
2. İçindəki index.html, style.css, script.js və assets qovluğunu repository-nin əsas qovluğuna yüklə.
3. Mövcud faylların üzərinə yazmağa razılıq ver.
4. GitHub > Settings > Pages bölməsində main / root seçimi olduğu kimi qalsın.

Qeyd:
